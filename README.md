# Старт ЛНР — публичный каталог стартов

Откройте `open_demo.bat` на Windows или запустите `python -m http.server 8765` из этой папки и перейдите на `http://127.0.0.1:8765`.

## Что доступно

- Переключать месяцы, открывать старты и листать горизонтальный слайдер; фильтры «Все», «Предстоящие», «Прошедшие» работают по дате, а не по наличию результата.
- Просматривать 26 местных стартов из `Календарный план.xlsx` и 23 предложения по выездам из `Таблица_по_выездным_на_2026_год_легкая_атлетика.xlsx` (лист «данные», строки 5–27). Для выездов даты включают приезд и отъезд. Наличие старта в предложениях **не подтверждает поездку или фактический состав команды**. Финансовые данные из таблицы на сайт не переносились.
- Открыть публикации MAX с файловыми вложениями [1](https://max.ru/id9403006509_gos/AZxfyqD9YjM) и [2](https://max.ru/id9403006509_gos/AZ8TdUbrYdU), а также официальные каналы [Telegram](https://t.me/sdushorlugansk) и [MAX](https://max.ru/id9403006509_gos).
- Составить локальный текстовый черновик заявки тренера. Для отправки администратору нужен согласованный канал связи; заполнение формы **не отправляет** заявку и **не публикует** карточку.

**Календарь содержит 26 соревнований из раздела «Легкая атлетика» предоставленного файла `Календарный план.xlsx` (строки 258–284; план на 2026 год, приказ Минспорта ЛНР от 26.12.2025 № 194).** Названия, даты, места и возрастные группы перенесены из плана, названия дисциплин представлены кратко. План не подтверждает факт проведения соревнований или их результаты; перед участием дату необходимо уточнять у организатора. Сроки приёма заявок, отдельные регламенты, расписания и протоколы не предоставлены. Статус «Дата прошла» означает только истечение даты по плану.

**Проверенных персональных результатов и подтверждённых карточек тренеров пока нет.** Ссылки MAX ведут на публикации с вложениями типа «Файл», но публичная страница не показывает содержимое, названия и PDF-адреса файлов без входа в веб-приложение. Поэтому ссылки не привязаны к конкретным стартам; рейтинг, фотографии прошедших стартов и сведения о наших спортсменах не выдумываются. Для публикации результатов нужны сами PDF либо доступные ссылки на их содержимое; для фото — проверенные публикации с изображениями. Официальный каталог мероприятий: [ВФЛА](https://rusathletics.info/meropriyatiya/calendar/).

Сайт на GitHub Pages публичен и не имеет входа в систему, серверной базы, отправки заявок или кабинета администратора. **Публичное редактирование плана и согласование выездов удалены.** Изменять опубликованные данные можно только через обновление исходных файлов владельцем репозитория. Тренерский черновик создаётся и скачивается только в браузере посетителя; он никуда не отправляется. Для реальной отправки и защищённого согласования нужен отдельный серверный сервис или утверждённый адрес администратора.

Реальные публикации Telegram сейчас не удаётся получить из сети разработки, а публичная страница MAX не отдаёт сами сообщения без веб-приложения. Поэтому лента явно помечена как демонстрационная, без выдуманной автосинхронизации и повторов; ссылки на оба настоящих канала работают. Для автоматической объединённой ленты позже понадобится доступный официальный API/виджет или публикация новостей администратором на сайте.

## Развёртывание

На GitHub Pages публикуйте **только содержимое этой папки**: Settings → Pages → Deploy from a branch → `main` / `(root)`. Не размещайте корень рабочей папки с `athletics.sqlite3`. `vercel.json` используется лишь при отдельном развёртывании на Vercel. Изображение `emblem-focus.jpg` — кадрированный фрагмент предоставленного визуального референса `Дизайн.jfif`, без названия учреждения в кадре.

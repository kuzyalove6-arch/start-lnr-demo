# Старт ЛНР — презентационное демо

Откройте `open_demo.bat` на Windows или запустите `python -m http.server 8765` из этой папки и перейдите на `http://127.0.0.1:8765`.

## Что можно попробовать

- Переключать месяцы и нажимать на даты местных соревнований; когда на один день приходится несколько стартов, выбирать событие из списка. Перейти к разделам итоговых протоколов и рейтинга из навигации.
- Перейти в «Редактировать план», сменить дату, срок приёма и статус, добавить PDF регламента/расписания/итогового протокола. Изменения видны сразу в календаре и карточках.
- Предложить демонстрационный выезд. Календарь ВФЛА доступен отдельной ссылкой; он не подтверждает участие представителей ЛНР в каждом из его стартов.
- Открыть справочник тренеров и официальные каналы [Telegram](https://t.me/sdushorlugansk) и [MAX](https://max.ru/id9403006509_gos).

**Календарь содержит 26 соревнований из раздела «Легкая атлетика» предоставленного файла `Календарный план.xlsx` (строки 258–284; план на 2026 год, приказ Минспорта ЛНР от 26.12.2025 № 194).** Названия, даты, места и возрастные группы перенесены из плана, названия дисциплин представлены кратко. План не подтверждает факт проведения соревнований или их результаты; перед участием дату необходимо уточнять у организатора. Сроки приёма заявок, отдельные регламенты, расписания и протоколы не предоставлены. Статус «Дата прошла» означает только истечение даты по плану.

**Спортсмены и тренеры в демонстрационном образце вымышлены.** План выездов пока не предоставлен; нет подтверждённых ФИО, результатов и разрядов для «Наших спортсменов» и топ‑5. В карточках и соответствующих разделах показаны пустые состояния, а не вымышленные достижения. Официальный каталог мероприятий: [ВФЛА](https://rusathletics.info/meropriyatiya/calendar/). Для размещения результатов понадобятся ссылки на протоколы, план поездок, история результатов и согласованная методика сравнения дисциплин.

Демо не имеет входа в систему, серверной базы или отправки заявок. Введённые данные и выбранные PDF доступны лишь в текущей вкладке до обновления страницы; на GitHub Pages они не отправляются. Используйте только условные обозначения, без настоящих персональных данных.

Реальные публикации Telegram сейчас не удаётся получить из сети разработки, а публичная страница MAX не отдаёт сами сообщения без веб-приложения. Поэтому лента явно помечена как демонстрационная, без выдуманной автосинхронизации и повторов; ссылки на оба настоящих канала работают. Для автоматической объединённой ленты позже понадобится доступный официальный API/виджет или публикация новостей администратором на сайте.

## Развёртывание

На GitHub Pages публикуйте **только содержимое этой папки**: Settings → Pages → Deploy from a branch → `main` / `(root)`. Не размещайте корень рабочей папки с `athletics.sqlite3`. `vercel.json` используется лишь при отдельном развёртывании на Vercel. Изображение `emblem-focus.jpg` — кадрированный фрагмент предоставленного визуального референса `Дизайн.jfif`, без названия учреждения в кадре.

# Старт ЛНР — публичный каталог стартов

Откройте `open_demo.bat` на Windows или запустите `python -m http.server 8765` из этой папки и перейдите на `http://127.0.0.1:8765`.

## Что доступно

- Переключать месяцы, открывать старты и листать горизонтальный слайдер; фильтры «Все», «Предстоящие», «Прошедшие» работают по дате, а не по наличию результата.
- Просматривать 26 местных стартов из `Календарный план.xlsx` и 23 предложения по выездам из `Таблица_по_выездным_на_2026_год_легкая_атлетика.xlsx` (лист «данные», строки 5–27). Для выездов даты включают приезд и отъезд. Наличие старта в предложениях **не подтверждает поездку или фактический состав команды**. Финансовые данные из таблицы на сайт не переносились.
- Открыть официальные каналы [Telegram](https://t.me/sdushorlugansk) и [MAX](https://max.ru/id9403006509_gos). В разделе протоколов оставлены только названия рабочих PDF и статус проверки; прямые ссылки на публикации с первого экрана удалены.
- Открыть форму тренера с кнопкой «Подать на добавление». Пока запись сохраняется только в браузере посетителя, реальный администратор её с другого устройства не получает.
- Подать заявку тренера, предложение по выезду, кандидатуру или заявку представителя на предстоящий местный старт. Они попадают в локальную очередь `admin.html`, где демонстрационный администратор может отметить заявку как утверждённую, отклонённую или требующую уточнения. Заявка представителя не является официальной регистрацией у организатора.
- В заявке представителя указываются команда, ФИО представителя и список спортсменов: ФИО, дата рождения, разряд и несколько видов программы для каждого.

**Календарь содержит 26 соревнований из раздела «Легкая атлетика» предоставленного файла `Календарный план.xlsx` (строки 258–284; план на 2026 год, приказ Минспорта ЛНР от 26.12.2025 № 194).** Названия, даты, места и возрастные группы перенесены из плана, названия дисциплин представлены кратко. План не подтверждает факт проведения соревнований или их результаты; перед участием дату необходимо уточнять у организатора. Сроки приёма заявок, отдельные регламенты, расписания и протоколы не предоставлены. Статус «Дата прошла» означает только истечение даты по плану.

Топ‑5 подсчитан по строкам итоговых таблиц восьми предоставленных PDF 2025–2026 годов (в том числе по отдельным дисциплинам и итоговому протоколу четырёхборья). Место 1 считается победой, места 1–3 — призовыми; сортировка по победам, затем по общему числу призовых мест. Страницы первоисточников перечислены в карточках. Разряд переписан из строк, не является подтверждением присвоения. Рабочие PDF остаются за пределами публичной папки `demo`, а подсчёт требует сверки с опубликованными документами перед официальным применением. Для выездов результаты и составы по-прежнему не публикуются без отдельной сверки с протоколами ВФЛА. Для каждого местного события генерируется отдельная тематическая SVG-иллюстрация; портреты тренеров — иллюстрации, а не фотографии. В hero используется предоставленная эмблема без нижней надписи из `emblem-no-text.png`. Официальный каталог мероприятий: [ВФЛА](https://rusathletics.info/meropriyatiya/calendar/).

Сайт на GitHub Pages публичен и не имеет входа в систему или серверной базы. Страница `admin.html` — демонстрационный кабинет: очередь хранится только в `localStorage` текущего браузера, поэтому она не является общей защищённой очередью и не подходит для настоящих персональных данных. Для реальной отправки и защищённого согласования нужен отдельный серверный сервис или утверждённый адрес администратора.

В информационной ленте размещена подборка из трёх открытых публикаций ВФЛА от 18, 22 и 23 сентября 2026 года с датами, краткими пересказами и ссылками на исходные статьи. Это снимок на 25 сентября 2026 года, без автоматического обновления. Публикации Telegram и MAX не импортируются: ссылки на настоящие каналы школы работают, но доступного источника для автоматической объединённой ленты пока нет.

## Развёртывание

На GitHub Pages публикуйте **только содержимое этой папки**: Settings → Pages → Deploy from a branch → `main` / `(root)`. Не размещайте корень рабочей папки с `athletics.sqlite3`. `vercel.json` используется лишь при отдельном развёртывании на Vercel. Изображение `emblem-focus.jpg` — кадрированный фрагмент предоставленного визуального референса `Дизайн.jfif`, без названия учреждения в кадре.

# Старт ЛНР — презентационное демо

Откройте `open_demo.bat` на Windows или запустите `python -m http.server 8765` из этой папки и перейдите на `http://127.0.0.1:8765`.

## Что можно попробовать

- Переключать месяцы и нажимать на даты местных (синих) и выездных (оранжевых) соревнований; открывать регламент, расписание, протоколы и демонстрационную заявку.
- Перейти в «Редактировать план», сменить дату, срок приёма и статус, добавить PDF регламента/расписания/итогового протокола. Изменения видны сразу в календаре и карточках.
- Для выезда предложить кандидата; в демонстрационном кабинете администратора утвердить его, отказать или запросить уточнение. Предложить новое выездное соревнование.
- Открыть справочник тренеров и официальные каналы [Telegram](https://t.me/sdushorlugansk) и [MAX](https://max.ru/id9403006509_gos).

**Все спортсмены и тренеры вымышлены. Календарь, сроки, регламент и сообщения на сайте — примеры, не официальный план учреждения.** Демо не имеет входа в систему, серверной базы или отправки заявок. Введённые данные и выбранные PDF доступны лишь в текущей вкладке до обновления страницы; на GitHub Pages они не отправляются. Используйте только условные обозначения, без настоящих персональных данных.

Реальные публикации Telegram сейчас не удаётся получить из сети разработки, а публичная страница MAX не отдаёт сами сообщения без веб-приложения. Поэтому лента явно помечена как демонстрационная, без выдуманной автосинхронизации и повторов; ссылки на оба настоящих канала работают. Для автоматической объединённой ленты позже понадобится доступный официальный API/виджет или публикация новостей администратором на сайте.

## Развёртывание

На GitHub Pages публикуйте **только содержимое этой папки**: Settings → Pages → Deploy from a branch → `main` / `(root)`. Не размещайте корень рабочей папки с `athletics.sqlite3`. `vercel.json` используется лишь при отдельном развёртывании на Vercel. Изображение `emblem.jfif` — копия предоставленного визуального референса `Дизайн.jfif`.
